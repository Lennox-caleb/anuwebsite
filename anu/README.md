# ANU Online — Complete Website Package

## Quick Setup

1. **Database**: Import `database.sql` into MySQL
2. **Config**: Edit `includes/config.php` with your DB credentials + SITE_URL
3. **Admin Login**: http://yourdomain.com/anu/admin/login.php
   - Username: `admin` | Password: `password` (change immediately!)

## Admin Panel Features

| Page | What You Can Do |
|------|----------------|
| `admin/heroes.php` | ⭐ Upload/change hero images for every page, edit titles, subtitles, CTA buttons |
| `admin/news.php` | Create/edit/delete news stories with images |
| `admin/programs.php` | Manage all academic programs |
| `admin/events.php` | Create upcoming events and deadlines |
| `admin/gallery.php` | Bulk upload photos for gallery sections |
| `admin/faqs.php` | Add/edit FAQs for any page |
| `admin/clubs.php` | Manage clubs and societies |
| `admin/testimonials.php` | Manage student testimonials |
| `admin/messages.php` | Read contact form submissions |
| `admin/prayers.php` | Manage chaplaincy prayer requests |
| `admin/applications.php` | Track application inquiries |
| `admin/settings.php` | Colors, contact info, social links, stats |
| `admin/users.php` | Manage admin accounts |
